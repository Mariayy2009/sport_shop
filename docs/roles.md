# Роли: покупатель, продавец, администратор

| Что | Покупатель | Продавец | Администратор |
|---|---|---|---|
| Покупать, корзина, заказы, отзывы, вопросы | ✓ | ✓ | ✓ |
| Выставлять свои товары, менять и удалять их | | ✓ (только свои) | ✓ (любые) |
| Отвечать на вопросы покупателей | | ✓ (о своих товарах) | ✓ (о любых) |
| Статус заказа и «где товар» | | ✓ (заказы со своими товарами) | ✓ (все заказы) |
| Снимать товар с продажи | | | ✓ |
| Предупреждать продавца | | | ✓ |
| Читать предупреждения | | ✓ | |
| «Зал славы»: экспонаты | | | ✓ |

## Продавец

Профиль → **«Кабинет продавца»**:
- **Мои товары** — выставить новый товар (бренд — название магазина),
  изменить или удалить свой. Снятые администратором товары помечены
  красным с причиной.
- **Заказы** — заказы, где есть его товары: статус (новый / в пути /
  доставлен) и **«Где товар»** — текст, который покупатель видит в своём
  заказе: «Отправлен из Алматы, привезём 27 ноября».
- **Вопросы** — вопросы покупателей о его товарах; ответ подписан
  «Ответ продавца …». Ответить можно и прямо в карточке товара.
- **Предупреждения** — от администратора: причина, товар, пояснение.

В карточке товара покупатель видит **«Продавец: Budo Pro»**
(товары без продавца продаёт сам магазин SPORT).

## Администратор

Профиль → **«Панель администратора»**:
- **Товары** — у каждого товара меню: изменить, **снять с продажи** /
  вернуть в продажу, **предупредить продавца**. Причины: запрещённый
  товар, подозрение на мошенничество, неверное описание или фото,
  завышенная цена, другое — плюс пояснение. Снятый товар пропадает из
  каталога, поиска и подбора; продавцу автоматически приходит
  предупреждение.
- **Заказы** — все заказы: статус и «где товар».
- **Вопросы** — все вопросы: ответить или удалить.

## Как устроено в базе

- `sellers (user_id, shop_name)` — магазин пользователя: пользователь
  с магазином — продавец (в `users.role` он хранится как `customer`, так
  обновление базы не трогает таблицу пользователей).
- `products.seller_id`, `products.status` (`active` / `blocked`),
  `products.block_reason`.
- `orders.tracking_note` — «где товар».
- `seller_warnings` — предупреждения продавцам.

Обновление базы до версии 12 добавляет колонки и таблицы — корзина,
заказы и избранное сохраняются.

Пока это работает на данных телефона; на сервере PostgreSQL роли
появятся вместе со входом через сервер (шаг 2 перехода).
