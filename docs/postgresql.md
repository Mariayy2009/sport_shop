# Переход на PostgreSQL

Переходим постепенно, по шагам. После каждого шага приложение работает, и
в профиле всегда можно вернуться к данным на телефоне.

| Шаг | Что переезжает на сервер | Статус |
|---|---|---|
| 1 | Каталог: виды спорта, категории, товары, фильтры и поиск | **готово** |
| 2 | Пользователи и вход (пароли в виде хеша, токен входа) | дальше |
| 3 | Корзина, избранное, заказы | дальше |
| 4 | Отзывы и вопросы, панель администратора (изменение товаров) | дальше |
| 5 | Остатки на складе в реальном времени, телефон только кэширует | дальше |

Зачем: в SQLite на телефоне у каждого покупателя своя копия магазина, а при
новой версии базы данные стираются. В PostgreSQL один общий магазин для
всех телефонов, а изменения структуры делаются миграциями (Alembic) — без
потери данных.

## Как устроено

```
Телефон (Flutter) ──HTTP, Wi-Fi──► Сервер магазина (FastAPI, ноутбук, порт 8080) ──► PostgreSQL
```

- Сервер: папка `backend/` — Python, FastAPI, SQLAlchemy, Alembic.
- Номера товаров на сервере те же, что на телефоне. Поэтому корзина,
  избранное и заказы (пока на телефоне) работают и с каталогом с сервера.
- Демо-каталог для сервера (`backend/seed/catalog.json`) выгружается из
  тех же данных, что и база телефона: `flutter test tools/export_seed_test.dart`.

## Что сделать на ноутбуке (один раз)

### 1. Установить PostgreSQL

1. Откройте https://www.postgresql.org/download/windows/ → «Download the
   installer» → выберите версию **16** или **17** для Windows x86-64.
2. В установщике оставьте всё по умолчанию:
   - компоненты: PostgreSQL Server, pgAdmin 4, Command Line Tools
     (Stack Builder можно снять);
   - **пароль** для пользователя `postgres` — придумайте и **запишите**,
     он понадобится дальше;
   - порт **5432**, Locale — Default.
3. В конце снимите галочку «Launch Stack Builder» и нажмите Finish.

PostgreSQL запускается сам вместе с Windows, отдельно включать не нужно.

### 2. Python

Нужен **Python 3.10–3.12** (если ставили для сервера примерки — он уже есть).
https://www.python.org/downloads/ — в установщике отметьте
«Add python.exe to PATH».

### 3. Установить сервер магазина

1. Откройте папку проекта `backend` и запустите **`setup_windows.bat`**.
2. Первый раз откроется Блокнот с файлом `.env`. Замените `ВАШ_ПАРОЛЬ` на
   пароль из пункта 1, сохраните (Ctrl+S), закройте Блокнот и запустите
   `setup_windows.bat` ещё раз.
3. Скрипт создаст окружение, поставит библиотеки, создаст базу
   `sport_shop`, таблицы и заполнит демо-каталог. В конце: «Готово».

Файл `.env` с паролем остаётся только у вас на ноутбуке, в GitHub он не
попадает (он в `.gitignore`).

## Запуск

1. Запустите **`backend/run_server.bat`**. Он сначала применяет новые
   миграции (если они появились после `git pull`), потом запускает сервер.
2. В окне появится:
   `Сервер магазина запущен. Адрес для приложения: http://192.168.1.5:8080`
3. Windows спросит про брандмауэр — разрешите **в частных сетях**.

Окно не закрывайте, пока пользуетесь приложением в режиме сервера.

## Подключение телефона

1. Телефон и ноутбук в одной сети Wi-Fi.
2. В приложении: **Профиль → «Данные: на телефоне»** → введите адрес из окна
   сервера, например `192.168.1.5:8080` → «Подключить».
3. Пункт меню сменится на «Данные: сервер PostgreSQL», каталог загрузится с
   сервера. Адрес запоминается.

Вернуться: там же кнопка «Брать данные с телефона».
Эмулятор Android на том же ноутбуке: адрес `10.0.2.2:8080`.

Проверка без телефона: в браузере ноутбука откройте
http://localhost:8080/health — должно быть `"status":"ok"` и число товаров.
Список товаров: http://localhost:8080/products, документация API:
http://localhost:8080/docs.

## Посмотреть базу глазами

Откройте **pgAdmin 4** (ставится вместе с PostgreSQL) → Servers →
PostgreSQL → введите пароль → Databases → `sport_shop` → Schemas → public →
Tables → правой кнопкой на `products` → View/Edit Data → All Rows.

## Если не работает

| Сообщение | Что делать |
|---|---|
| `password authentication failed` | В `backend/.env` неверный пароль — исправьте и запустите `setup_windows.bat` снова |
| `connection refused` / `Is the server running` | PostgreSQL не запущен: Пуск → «Службы» → `postgresql-x64-16` → Запустить |
| Телефон пишет «Сервер магазина недоступен» | Окно `run_server.bat` открыто? Брандмауэр (частные сети)? Одна сеть Wi-Fi? Откройте в браузере телефона `http://<адрес>:8080/health` |
| «Изменение товаров на сервере появится на следующем шаге» | Это нормально на шаге 1: для панели администратора переключитесь на данные телефона |

Любую другую ошибку из окна пришлите целиком.

## Ограничения шага 1

- С сервера берётся только каталог. Вход, корзина, избранное, заказы,
  отзывы пока хранятся на телефоне.
- Панель администратора в режиме сервера не изменяет товары (появится на
  шаге 4 вместе со входом через сервер — иначе изменять каталог мог бы
  любой в сети).
- Сервер без HTTPS и пароля — только для домашней сети, не для интернета.

## Файлы

| Файл | Что делает |
|---|---|
| `backend/app/main.py` | REST API: `/health`, `/sports`, `/categories`, `/products`, `/products/{id}` |
| `backend/app/models.py` | Таблицы (SQLAlchemy) |
| `backend/migrations/versions/` | Миграции Alembic — история изменений структуры базы |
| `backend/seed.py` | Заполнение демо-каталогом (`--reset` — перезаписать) |
| `backend/create_db.py` | Создание базы `sport_shop` |
| `backend/tests/test_api.py` | Тесты API на настоящем PostgreSQL |
| `lib/data/datasources/remote/shop_api_client.dart` | HTTP-клиент приложения |
| `lib/data/repositories/api_product_repository.dart` | Каталог с сервера |
| `lib/data/repositories/switchable_product_repository.dart` | Переключение телефон ↔ сервер |
| `lib/state/data_source_state.dart` | Подключение, адрес, ошибки связи |
| `lib/widgets/shop_server_sheet.dart` | Окно подключения в профиле |
